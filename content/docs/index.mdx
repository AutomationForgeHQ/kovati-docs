## How to read this wiki

Every page carries a chip under its title saying how far to trust it.

- **Documented in depth** — written against the source, used in a real
  production, and honest about where the edges are. Today that is
  [MotionForge](/docs/automation-forge/motionforge),
  [MeshForge](/docs/automation-forge/meshforge),
  [SpeechForge](/docs/automation-forge/speechforge),
  [FaceForge](/docs/automation-forge/faceforge) and
  [PerformanceForge](/docs/automation-forge/performanceforge).
- **Overview** — what it is and what it does, without the detail. The plugin's
  own README goes further until the page catches up.
- **Not released** — described because it is being built. Nothing in it is
  installable.

No page on this site types a version number, a download link or a release date
by hand. All of that is read from
[the release manifest](https://github.com/AutomationForgeHQ/automation-forge/blob/main/manifest.json),
which CI generates from the plugin register and the published releases. If you
find a number here that contradicts what the hub tells you, the hub is right
and this is a bug — [open an issue](https://github.com/AutomationForgeHQ/kovati-docs/issues).

This page is generated from the plugin's own node catalog, not written by hand.
Each native node carries its catalog entry in its source file, and the editor's
node library, the node inspector and the agent tool `ListNodeTypes` all read
that same entry. The labels, descriptions, ports, defaults and ranges below are
copied from it.

To regenerate after the catalog changes, from the root of the wiki repository:

```powershell
node tools/export-terrainforge-nodes.mjs <path to the TerrainForge plugin folder>
node tools/gen-terrainforge-nodes.mjs
```

The first reads the source and writes `data/terrainforge-nodes.json`; the
second writes this page from that file.

<Callout type="info">
  **Every node runs natively.** There is no node that needs another program or
  a service. Where a node has a GPU kernel and the Compute setting allows it,
  part of it runs on the graphics card; the result is checked against the CPU
  version. See [GPU compute](/docs/automation-forge/terrainforge#gpu-compute).
</Callout>

## Reading the tables

- **Ports** carry one of four kinds of data: *elevation* (a heightfield in
  metres), *mask* (0 to 1), *colour* (sRGB, for display) and *RGB data* (linear
  packed masks). They are not interchangeable: validation refuses a link between
  different kinds.
- An input marked **optional** can stay unconnected. A required input must be
  connected before that branch can be previewed or built.
- **Distances and heights are in metres**, areas in square metres, angles in
  degrees, unless the label says otherwise. Positions are metres from the map
  centre, X east and Y south.
- **"New nodes start at"** marks a parameter whose default for a new node
  differs from the value an older saved graph keeps. Saved graphs are not
  changed by an update.
- **Runtime only** marks the per-node `compute` choice (`auto`, `cpu`,
  `gpu`). It decides where the node runs, not what it computes.

Where bare rock shows: steep faces above the angle where soil holds, and convex crests and edges on steep ground, plus an optional exposed-rock input. Slope and curvature are measured over a scale in metres, so preview and build grids agree.

- **Inputs:** `terrain` (elevation), `exposedRock` (mask, optional)
- **Outputs:** `mask` (mask)

| Parameter | Default | Allowed |
|---|---|---|
| Measure scale (m) `measureScale` | 20 | 0 to 1000, step 1 |
| Rock starts at (°) `rockSlope` | 32 | 0 to 89, step 1 |
| All rock above (°) `cliffSlope` | 50 | 1 to 90, step 1 |
| Crests weight `convexityWeight` | 0.5 | 0 to 2, step 0.05 |
| Curvature white at (1/m) `curvatureRef` | 0.004 | 0.0001 to 1, step 0.0005 |
| Exposed rock weight `exposedWeight` | 1 | 0 to 4, step 0.05 |

### Soil map

Type `SoilMap`.

Where soil and sediment lie: gentle slopes, hollows and valley floors, drainage paths and deposition. Slope and curvature are measured over a scale in metres and flow by specific catchment area, so preview and build grids agree. Without a flow input the node routes the terrain itself.

- **Inputs:** `terrain` (elevation), `flow` (mask, optional), `deposition` (mask, optional)
- **Outputs:** `mask` (mask)

| Parameter | Default | Allowed |
|---|---|---|
| Measure scale (m) `measureScale` | 20 | 0 to 1000, step 1 |
| Full soil below (°) `soilSlope` | 20 | 0 to 89, step 1 |
| Bare above (°) `bareSlope` | 40 | 1 to 90, step 1 |
| Soil on plain slopes `baseSoil` | 0.5 | 0 to 1, step 0.05 |
| Hollows weight `concavityWeight` | 0.35 | 0 to 1, step 0.05 |
| Curvature white at (1/m) `curvatureRef` | 0.004 | 0.0001 to 1, step 0.0005 |
| Flow weight `flowWeight` | 0.35 | 0 to 1, step 0.05 |
| Flow white at catchment (m) `flowRef` | 5000 | 1 to 10000000, step 100 |
| Deposition weight `depositionWeight` | 1 | 0 to 4, step 0.05 |

## Color

Colour and packed-data outputs for materials. They do not change the terrain.

### Terrain palette

Type `Palette`.

Map terrain elevation or an optional mask guide through an original five-color ramp. These are authored palettes, not satellite imagery.

- **Inputs:** `terrain` (elevation), `guide` (mask, optional)
- **Outputs:** `color` (colour)

| Parameter | Default | Allowed |
|---|---|---|
| Palette `palette` | `alpine` | `alpine`, `desert`, `moss`, `volcanic`, `custom` |
| Elevation range `range` | `relative` | `relative`, `absolute` |
| Low elevation (m) `low` | 0 | -10000 to 20000, step 50 |
| High elevation (m) `high` | 2200 | -10000 to 20000, step 50 |
| Guide enhancement `enhance` | `none` | `none`, `autolevel`, `equalize` |
| Ramp bias `bias` | 1 | 0.1 to 8, step 0.05 |
| Reverse ramp `reverse` | off | on or off |
| Custom color at 0% `color0` | `#343e29` | an sRGB colour |
| Custom color at 25% `color1` | `#667047` | an sRGB colour |
| Custom color at 50% `color2` | `#948977` | an sRGB colour |
| Custom color at 75% `color3` | `#c3bcae` | an sRGB colour |
| Custom color at 100% `color4` | `#e7e8e3` | an sRGB colour |

### Solid color

Type `SolidColor`.

A uniform sRGB color for masked biome and surface layers.

- **Inputs:** none
- **Outputs:** `color` (colour)

| Parameter | Default | Allowed |
|---|---|---|
| Color `color` | `#aaa08c` | an sRGB colour |

### Two-color tint

Type `Tint`.

Map a mask between two sRGB colors. Input enhancement is explicit and off by default.

- **Inputs:** `mask` (mask)
- **Outputs:** `color` (colour)

| Parameter | Default | Allowed |
|---|---|---|
| Dark color `start` | `#3c4933` | an sRGB colour |
| Light color `end` | `#ded5b6` | an sRGB colour |
| Mask enhancement `enhance` | `none` | `none`, `autolevel`, `equalize` |
| Reverse ramp `reverse` | off | on or off |

### Blend colors

Type `ColorCombine`.

Blend two color layers through opacity and an optional mask. Linear-light mixing is the default; artistic sRGB blending is also available.

- **Inputs:** `a` (colour), `b` (colour), `mask` (mask, optional)
- **Outputs:** `color` (colour)

| Parameter | Default | Allowed |
|---|---|---|
| Operation `mode` | `mix` | `mix`, `multiply`, `screen`, `overlay`, `soft_light`, `hard_light`, `add`, `subtract`, `difference`, `min`, `max` |
| Opacity `amount` | 1 | 0 to 1, step 0.05 |
| Blend space `space` | `linear` | `linear`, `srgb` |

### Adjust color

Type `ColorAdjust`.

Hue rotation, saturation, lightness and gamma for sRGB colors. A mask limits adjustments; packed data is a separate type.

- **Inputs:** `color` (colour), `mask` (mask, optional)
- **Outputs:** `color` (colour)

| Parameter | Default | Allowed |
|---|---|---|
| Hue shift (°) `hue` | 0 | -360 to 360, step 5 |
| Saturation scale `saturation` | 1 | 0 to 3, step 0.05 |
| Lightness shift `lightness` | 0 | -1 to 1, step 0.05 |
| Gamma `gamma` | 1 | 0.1 to 5, step 0.05 |

### Pack RGB masks

Type `RGBMerge`.

Pack R/G/B masks as linear data. No gamma conversion. Each channel can optionally be enhanced; leave None for calibrated masks.

- **Inputs:** `r` (mask), `g` (mask), `b` (mask)
- **Outputs:** `packed` (RGB data)

| Parameter | Default | Allowed |
|---|---|---|
| R enhancement `enhancer` | `none` | `none`, `autolevel`, `equalize` |
| G enhancement `enhanceg` | `none` | `none`, `autolevel`, `equalize` |
| B enhancement `enhanceb` | `none` | `none`, `autolevel`, `equalize` |

### Unpack RGB masks

Type `RGBSplit`.

Recover the exact R/G/B masks from packed linear data. The average output is an arithmetic mean. Color textures are a distinct type.

- **Inputs:** `packed` (RGB data)
- **Outputs:** `r` (mask), `g` (mask), `b` (mask), `average` (mask)

No parameters.

## Export

The node whose terrain becomes the build output.

### Terrain output

Type `Output`.

The height field used for builds. Water routing and paint maps run after this node.

- **Inputs:** `terrain` (elevation)
- **Outputs:** `terrain` (elevation)

No parameters.

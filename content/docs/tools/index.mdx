Not everything Kovati builds belongs to a Forge set. Some things are one
capability a production needed, with no family around them; others are bridges
that connect Automation Forge to a framework you have already chosen.

The naming rule is simple: **if it carries *Forge* in its name it is part of
the Automation Forge family**, and it lives under
[Automation Forge](/docs/automation-forge). Everything else is here.

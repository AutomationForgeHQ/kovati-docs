## 0.5.x

### 0.5.0

*22 September 2026*

#### Added
- Kimodo's own settings on every definition: model, seed, diffusion steps, postprocess, beat splitting, and - under Advanced - separated guidance (`cfg_text`, `cfg_constraint`) and where poses come from.
- **Direct**, in the definition window: a plain guide to beats, poses at moments, guidance and seeds, and actions beside it - *Pin a pose from an animation* at the start, the end, both or a moment; *Show what will be sent*; *Clear authored poses*; *Measure the imported clip*.
- Generate starts a stopped local runner - Docker first if it is closed - and waits for the text encoder, instead of refusing.
- The Kimodo Runner panel gains **Another machine**: point the project at a studio workstation's runner, with its token kept in this computer's vault and the commands to start it there.
- **Llama 3 access is measured**, not assumed: Hugging Face is asked whether the stored token can read the gated model, and the answer - granted, not granted yet, token refused - is shown with the link to request it.
- Setup steps for Get started: where it runs, Docker, the token, Llama 3 access, the image, the runner, and renting a GPU instead.

#### Changed
- Cost follows where it runs: free on this machine or another, per hour on a rented GPU, which bills while the pod is up whether or not anything generates.
- The character's route and actions come from Kimodo: *Build Kimodo rig* for IK on the feet, *Import directly instead* to skip it.
- Building a Kimodo rig marks the character as Kimodo's. Left universal, it could be offered to another provider, which would then have retargeted its own clips through Kimodo's rig.

#### Fixed
- Poses keyed only on the prompt timeline reach the runner.
- A rotation a little off orthonormal no longer fires an engine ensure while a clip is read.
- The README and the plugin's own messages name the real console commands: `Kimodo.PreviewConstraints`, `Kimodo.Measure`, `Kimodo.Diagnose`.

#### Compatibility
- Needs MotionForge 0.4.0 or later.

#### Known issues
- The runner's compose file publishes port 8757 on every network interface, while its comments describe a loopback-only desktop runner. Set `KIMODO_API_TOKEN` on any machine the network can reach.
